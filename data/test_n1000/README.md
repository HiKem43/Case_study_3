# Test dataset: 1,000 students

This dataset contains 8 courses, 1,000 students, 4 rooms, and 4 time slots.
Each group of 250 students registers for one pair of courses, giving each
course 250 registered students and a valid schedule within the supplied room
capacities and time slots.

Run from the `Case_study_3` directory:

```powershell
.\main.exe data\test_n1000\data_Config.txt
```

The input format is the same as the standard files in `data/`.
